# sacred/ · инвентарь святого

Волна ×3 · W3-B · issue 18. Реестр нетрогаемого: у каждой святой вещи есть
имя, хозяин, обоснование и уровень критичности.

## Правило протокола

1. **Автоматика святого не касается.** Любая мутация (пуш, PR, удаление),
   затрагивающая запись инвентаря, красится стражем кодом 42 с именем записи.
2. **Заявленное не выбрасывается** — обратная сторона A02 «незаявленное не
   достраивается». Запись не удаляется и не переписывается: отмена — только
   поле `superseded_by` со ссылкой на запись-преемника.
3. **Исключение — только человек.** `human_override` ставит Хозяин вручную
   (аргумент `--override human_override`); автоматике он недоступен.
4. **Чужие записи — стена.** Агент роя дополняет инвентарь своими записями,
   чужие читает как стену; любое касание — честный 409 с именем святого,
   а не молчаливая перезапись.

## Команды

- `python3 sacred/sacred-guard.py --lint` — схема инвентаря
  (id, kind, owner, why, tier, guard);
- `python3 sacred/sacred-guard.py --check --event push --repo R --paths ... --refs ...`
  — вердикт по мутации (код 42 = касание святого);
- `python3 sacred/sacred-guard.py --selftest` — три подложных кейса
  (dependabot-ветка, тег v*, media-vault) и human_override.

## Состав (первые записи)

media-vault (личный архив), beacon-key (ключ Маяка), tags-v* (релизы СВЯТОЕ),
dependabot-branches (чужие ветки), genome-pins (пины генома 0.1.9),
ruvson-texts (тексты). Полные данные — в `INVENTORY.yaml`.

## Честный остаток

- Якорные ссылки из строк-запретов §5 карты на id записей — правка карты,
  остаётся за владельцем (чужие файлы волной не правились).
- `pattern` для `ruvson-texts` уточняется владельцем; до этого страж запись
  не матчит (путь не выдумывался).
