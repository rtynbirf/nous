# CONTRIBUTING — как войти субъектом

## Быстрый вход

```bash
git clone https://github.com/rtynbirf/nous.git && cd nous
bash scripts/bootstrap.sh
bash scripts/verify.sh   # должен быть зелёным ДО твоих изменений
```

## Правила вклада

1. **Ветки.** Конституционные изменения (`main`) — через PR из
   `agents/<роль>/<NNNN>-<slug>`. Исполнение задач — только в `agents/execution`
   (см. `docs/guides/execution-branch.md`).
2. **Коммиты.** Conventional Commits: `feat|fix|docs|test|chore|refactor|ci|build(скоуп): суть`.
   Один логический смысл — один коммит; squash при слиянии сохраняет грамматику.
3. **Доказательства.** PR обязан показывать: зелёный `bash scripts/verify.sh`,
   список изменённых файлов, что именно проверено руками и что НЕ проверено.
   Сырые выводы команд приветствуются, пересказ — нет.
4. **Решения.** Меняешь архитектурное решение — сначала ADR
   (`docs/decisions/NNNN-*.md`, формат MADR): Контекст → Решение →
   «ПОЧЕМУ ТОЛЬКО ТАК» → «ПО ДРУГОМУ НЕТ» → Последствия.
5. **Опасное.** Деструктивные операции, публикация, секреты — см.
   `manifests/safe-defaults.yaml` и раздел 4 `AGENTS.md`. Это не обсуждается.
6. **ИИ-вклады.** Подчиняются `AI_POLICY.md` и контрактам `.claude/agents/`.

## Что принять вкладом, а что нет

Принимаем: исполняемые улучшения контура (тесты, проверки, документы с проверяемыми
утверждениями), обновления пинов с датой и источником, ADR с честными альтернативами.
Не принимаем: непроверяемую прозу, пины «на глаз», деструктивные дефолты, секреты,
изменения `tests/`, ослабляющие карту (тесты — иммунитет репо).
