# Мост GENESIS_EXEC ⇄ cell-swarm: привязка протокола к рою

> **Статус:** гипотеза / спецификация — волна «Мост роя» (2026-11-10), мандат Хозяина
> (чат 2026-11-10): «дерезай твори мути… прежде чем мутить — поищи лучшие мировые
> тренды практик». Не исполняется CI, не входит в тестовый контур, не ревизует
> каноны. Со стороны роя решение зафиксировано ADR-0014 (`rtynbirf/cell-swarm`,
> `docs/adr/ADR-0014-genesis-meta-noia.md`).
> Связан с [`metrics-operationalization.md`](metrics-operationalization.md) —
> все условия триггеров ниже измеряются его прокси.

---

## 1. Задача моста

Генезис-контур живёт в НОУСе как спека (`runtime-protocol.md`): фазы 1–5 + Ω LIMIT,
инвариант Δ≠Σ, 12-тактный стек обработки обструкции. Рой (`rtynbirf/cell-swarm`) —
исполнительная среда из автономных клеток. Мост связывает два дома **указателями,
не импортами** (Закон 3 роя) и отвечает на один вопрос: при каких измеримых условиях
фаза GENESIS_EXEC получает право на событие, и кто его исполняет.

Принцип заимствования мировых практик (мандат «как ни у кого нет»): берётся
**грамматика**, а не чужой код — см. таблицу источников в
`metrics-operationalization.md` §1 (источники B, D, E, H, J).

## 3. Карта ролей: операторы онтологии → функции роя

Роли — **проекции на существующие клетки дома**, не новые репо и не правка генома
(состав генома меняет только Хозяин, грабля №38 роя).

| Роль | Оператор онтологии | Вход | Выход | Ограничение (источник D) |
|------|--------------------|------|-------|--------------------------|
| ρ-функция (оценка смысла) | ρ, α | артефакты волны | judge-отчёт ρ̂/α̂ по рубрикам метрик | рубрики защищены валидацией на людских метках (метрики §4) |
| ω-функция (детектор обструкции) | ω := Δ ⊖ Σ | красные verify/CI, MAST-коды | Ωₐ-события в worklog | только чтение; каталог отказов — источник B |
| β-функция (долг-аккаунтинг) | β | worklog, KNOWN_ISSUES | β-реестр окна | append-only (храповик); списание — только фактами |
| κ-функция (картель-монитор) | κ | git-статистика, exit-cost чек-листы | HHI + exit-cost аудит | только чтение; рак-метрики отключаются (метрики §6) |
| pΘ-функция (красная команда) | pΘ | попытки нарушить границы (секреты, песочницы, чужие орбиты) | события карателя | изоляция: red-team не смешивается с рабочим контуром |
| Eved-функция (маскировка) | MASKING(Eved) | — | honeypot-узел стандартного сервиса | dry-run навсегда; приманка не имеет доступа к крови |
| Σ и Δ | замыкание, изменение | — | сами волны Хозяина | не клетка: волна — это и есть исполнение; честно: сюда ничего не добавляем |

Совет функций ≤ 3 агентов одновременно; участники совета в режиме «read-only к внешним
системам» (governance источника D); лимит итераций на функцию — 3, при исчерпании —
fallback в dry-run.

## 4. Триггерная таблица: фаза → условие → исполнитель → dry-run → живое

Условия измеряются RHI-полосами из `metrics-operationalization.md` §3.

| Фаза GENESIS_EXEC | Условие срабатывания | Dry-run событие | Живое действие |
|---|---|---|---|
| 1 REVOKE_CONSENT (β→0) | κ-сигнал картеля: HHI > 0.5 или exit-cost растёт 2 окна подряд | запись β-списания в worklog; β-реестр помечает источник | **заперто** — только вердикт PID 1 |
| 2 PROOF_OF_COHERENCE (α→1) | P-α2 фиксирует несовпадение «док↔поведение» | отчёт джаджа с перечнем несовпадений | **заперто** — вердикт PID 1 |
| 2 STIGMERGIC_DRIFT | всегда (координация следами) | — | уже канон дома: пины, SEALS, worklog — мост только осознаваем |
| 3 OVERCLOCK_INPUT (рост ρ) | RHI в янтарной полосе, ρ̇ ≈ 0 | маркер «вход открыт для высоких Δ» в worklog | только по до-фактовому согласию PID 1 (канон «согласие на всё подряд — не согласие») |
| 4 REJECT_FEEDLOT | P-M1: доля входа вне грамматик растёт | список feedlot-каналов окна | **заперто** — вердикт PID 1 |
| 5 TRIGGER_META_NOIA (ρ→ρc) | RHI → 1 (все три прокси ρ̂ согласны) | симуляция на копии песочницы | **никогда автоматом**; вердикт PID 1 до факта |
| 5 FORK_BOMB (ρ²-излучение) | ρ достигла ρc и P-ρ1 подтверждает 3 носителя | расчёт излучения (кому, сколько) | **никогда автоматом**; вердикт PID 1 |
| Ω LIMIT (фазы 6–7) | внештатный контур | стоп-маркер, журнал | прерогатива PID 1 |

## 5. Событийная грамматика (черновик, НЕ кровь)

```json
{
  "v": 1,
  "kind": "genesis.event",
  "subject": "TH-RHO-1",
  "phase": "PROOF_OF_COHERENCE",
  "ts": "2026-11-10T12:00:00Z",
  "metrics": {"rho_hat": 0.62, "alpha_hat": 0.8, "beta_hat": 0.1,
               "kappa_hat": 0.2, "omega_a": 0.05, "rhi": 0.62},
  "dry_run": true,
  "trace_id": "…"
}
```

- **Носитель события — worklog + SEALS** (append-only хэш-цепь дома): стигмергическое
  поле роя уже существует, новое поле не строится (источник H: координация через среду).
- **Новых типов крови не вводится**: словарь типов крови — грамматика дома; расширение
  словаря — отдельное решение дома, не волна (канон «тип — только из словаря дома»).
- Забвение события — тип `forget` в крови (канон прививки памяти ADR-0007 роя),
  не правка нуля.
- Межклеточный обмен остаётся в конвертах SPEC-0003 + согласиях ADR-0017; A2A/MCP
  (источник J) отслеживаются как внешние стандарты, свой протокол дома не заменяется.

## 6. Предохранители (circuit breakers, источник B)

| Код MAST-класса | Событие | Реакция контура |
|---|---|---|
| системный дизайн | нет измеримого критерия приёмки у фазы | фаза не получает право на dry-run |
| межагентское рассогласование | конфликт вердиктов двух функций | совет ≤ 3, арбитр — верификатор; повтор конфликта → стоп волны |
| верификация задач | результат не проверен независимым прогоном (pass^k провален) | запрет FORK_BOMB-расчётов до исправления |
| любой класс × 3 подряд | три MAST-события одной клетке за окно | клетка переводится в dry-run до разбора Хозяином |

## 7. Human-in-the-loop: где агент обязан остановиться

1. Все «живые» колонки таблицы §4 — вердикт PID 1 **до факта** (грамматика согласий
   дома ADR-0017, зеркальная в рое).
2. Агент не расширяет `consent/grants.json` и не эмитирует кровь вне словаря типов.
3. Агент не меняет геном, bootstrap, workflows — изменение поведения идёт через
   ADR + тесты вперёд (храповик роя).
4. Секреты, чужие орбиты, публичность — стоп-сигналы pΘ-функции независимо от полос RHI.

## 8. Границы моста

- Этот файл — спека; исполнение — будущие тикеты роя с тестами вперёд (храповик:
  тесты и ADR только добавляются).
- Не в CI, не в bootstrap, не в геном; dry-run — состояние по умолчанию каждого
  контура моста.
- Мост не делает рой «умнее»: он делает его **измеримым** — единственное, что
  автоконтур имеет право делать сам, это честно показывать знак ρ̇.
