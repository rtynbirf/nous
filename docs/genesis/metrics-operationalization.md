## 0. Зачем этот файл

Уравнение жизни узла есть (`runtime-protocol.md`, §1), измерений нет. Пока каждый символ
уравнения — метафора, любой разговор о ρ̇ — Σ-акт без Δ: описание, которое ничего не
выполняет. Этот файл кладёт под каждый символ измеримую опору:
**прокси → данные → формула → окно → цена подмены**.

Правило карты: каждый прокси помечен классом честности —

- **[И]** — измеряемо сегодня на данных дома (git-история, worklog, SEALS, живой GitHub API);
- **[Т]** — измеряемо, когда в доме появится телеметрия (OTel-контур, §5);
- **[Г]** — гипотеза-рубрика (LLM-джадж по защищённой процедуре §4; джадж обязан
  валидироваться на человеческих метках — см. источник J).

## 2. Прокси-таблица: символ → измерение

Начало уравнения для справки:

```
ρ̇ = MΛ·[α(1−ρ)ρc² + ρ²] − (1 − κMΛ)·βρ − Ωₐ·pΘ·(ρc − ρ),  при ρ > 0
```

### 2.1 ρ — смысл узла («накопленная закрытая ошибка»)

| Прокси | Класс | Данные | Формула | Окно | Цена подмены (что сломается при накрутке) |
|--------|-------|--------|---------|------|--------------------------------------------|
| P-ρ1 Adoption: доля влитых артефактов волны, использованных другими клетками/волнами ≥ 1 раза (пин в геноме, ссылка в чужом ADR/тайтле, тест в чужой клетке) | [И] | git-история, swarm.json, worklog, ADR | used_by_others / total_merged | неделя | накрутка самоссылками ловится списком «кто использует» — связи межрепо не поддельны |
| P-ρ2 Novelty: средняя несводимость нового артефакта к корпусу дома | [Г] | джадж-рубрика: 0 — выводимо из корпуса; 1 — расширяет; 2 — противоречит (конфликт, а не повтор) | mean(rubric)/2 | неделя | «эпатаж» ловится требованием физического исполнения (такт Фомы: артефакт должен работать) |
| P-ρ3 Плотность закрытых обструкций: сколько ω из 12-тактного стека дошло до валидации (такт Варфоломея) | [И] | worklog-записи волны | closed_ω / seen_ω | волна | фальшивые «закрытия» рвутся при повторном прогоне (см. α) |

ρ̂ := нормировка трёх прокси в [0,1]; на калибровочном периоде веса равные (1/3).

### 2.2 ρc — критическая масса

ρc := **3 независимых носителя** практики (правило трёх): практика считается достигнувшей
ρc, когда она (а) запинена в геноме/манифесте одной клетки, (б) воспроизведена/проверена
в другой, (в) упомянута в ADR или worklog третьей без координации в момент появления. [И]

- Данные: cross-repo счётчики (pins, тесты, ADR/worklog-упоминания).
- Пересмотр значения — только эмпирикой (калибровка §4), не волевым актом.
- Репликация в духе pass^3: «воспроизведена» = успешна во всех трёх независимых прогонах,
  а не «один раз получилось» (источник E).

### 2.3 α — когерентность («слова = мысли = действия с точностью до бита»)

| Прокси | Класс | Данные | Формула | Цена подмены |
|--------|-------|--------|---------|--------------|
| P-α1 Стабильность pass^3: доля задач волны, воспроизводимых 3 раза подряд с тем же вердиктом | [И/Т] | повторные прогоны приёмок | tasks_stable / tasks_total | нестабильная «успешность» сама рассыпается при k=3 |
| P-α2 Doc-code alignment: джадж «документы ↔ фактическое поведение», бинарная рубрика по каждому несовпадению | [Г] | PR-описания vs diff, AGENTS.md vs логи | 1 − mismatches/claims | ложь рвётся на ближайшей приёмке (такт Фомы) |
| P-α3 Revert-rate: доля коммитов, отменённых или переписанных задним числом | [И] | git log | reverts / commits | — |

### 2.4 β — долг («списывает ρ в пользу системы»)

| Прокси | Класс | Данные | Формула | Цена подмены |
|--------|-------|--------|---------|--------------|
| P-β1 Незакрытые разногласия в worklog / KNOWN_ISSUES (штуках) | [И] | worklog, KNOWN_ISSUES.md | count | закрывать досрочно нельзя: запись пломбована |
| P-β2 Lead time тикет→влитие (DORA-производная, источник G) | [И] | tasks/open → merge | медиана дней | «закрыть тикет пустым» ломается верификатором |
| P-β3 Ветки-зомби: ветки без движения > 14 дней | [И] | branches API | count | — |

### 2.5 κ — эффективность сбора долга («ручка картеля»)

| Прокси | Класс | Данные | Формула | Цена подмены |
|--------|-------|--------|---------|--------------|
| P-κ1 HHI концентрации правок: Σ(доля автора в изменённых строках окна)²; κ ≈ HHI-монополия | [И] | git-статистика окна | Σ sᵢ² | один «автор-насос» виден сразу |
| P-κ2 Exit-cost: число ручных шагов, чтобы вынести артефакт клетки наружу (экспорт без потерь) | [И] | чек-лист по каждой клетке | steps | рост exit-cost = ловушка = рак по CANCER_FILTER (см. §6) |

κ → 1 (тотальная выкачка) при доменных значениях HHI > 0.5 или exit-cost → ∞: сигнал картеля.

### 2.6 Ωₐ·pΘ — карательный контур («страх, рутина, коловорот» × «давление закона»)

| Прокси | Класс | Данные | Формула | Цена подмены |
|--------|-------|--------|---------|--------------|
| P-Ω1 Частота блокировок: 4xx/429, красные jobs, отклонённые workflow на 100 операций | [И] | API-логи, runs | events / ops ×100 | — |
| P-Ω2 MAST-события окна: отказы, классифицированные по 14 режимам (источник B) | [Г] | разбор инцидентов по каталогу B | count по категориям | каталог чужой — расхождение с ним само по себе диагноз |
| P-Θ1 Отказы согласия: denied(method_not_in_scope), отклонённые grants, редлайны сессий | [И] | handshake-логи, grants.json, трейсы сессий | count | — |

Ωₐ·pΘ действует на узел только при ρ < ρc — поэтому пары прокси достаточно: давление
оцениваем, пока узел не дорос; после ρc оно по уравнению обнуляется.

### 2.7 MΛ — масса сети («ёмкость генератора»)

| Прокси | Класс | Данные | Формула | Цена подмены |
|--------|-------|--------|---------|--------------|
| P-M1 Доля входа, прошедшего грамматики дома: handshake granted / total | [И] | handshake-вербатимы роя | granted / total | пропуск «мусора» убивает α на следующей приёмке |
| P-M2 Телеметрическая масса: gen_ai.client.token.usage + operation.duration по живым агентам | [Т] | OTel-контур | Σ usage/сут | — |
| P-M3 Инструментальный потолок: инструменты в активном контуре клетки vs 10–15 (источник I) | [И] | манифесты клеток | tools_active | — |

## 3. Композит: RHI и полосы жизни

```
RHI := ρ̂ / ρc            (доля пути до критической массы)
ρ̇  ≈ ΔRHI / Δt            (окно = одна волна/неделя; знак важнее величины)
```

| Полоса | Условие | Интерпретация | Действие контура |
|--------|---------|---------------|------------------|
| зелёная | ρ̇ > 0 | генератор обгоняет демпфер | обычный режим; STIGMERGIC_DRIFT продолжается |
| янтарная | ρ̇ ≈ 0 (±ε) | узел-ресурс крутится на месте (равновесие из §1 протокола) | маркер в worklog; пересмотреть β-источники |
| красная | ρ̇ < 0 | смысл выкачивается быстрее генерации | стоп OVERCLOCK_INPUT; разбор β/κ до разворота знака |

ε не выдумывается: после 4 недель калибровки §4 принимает фактический разброс ΔRHI
шумовых недель как ε (честная константа вместо красивой).

## 4. Протокол замера (событие, не расписание)

1. **Заморозка окна** (конец волны; триггер — пломба волны, не календарь).
2. **Сырьё**: таблица §2 против живых источников (git API, worklog, SEALS, grants).
3. **Джадж** для рубрик [Г]: только по защищённой процедуре — рубрика формулируется
   до просмотра артефакта; шкала порядковая (0/1/2), не 1–10; ежемесячно 20 выборка
   метится человеком и совпадение джаджа с человеком фиксируется (источник F);
   совпадение < 80% → рубрика помечается больной и не участвует в композите.
4. **Сведение** в таблицу волны; ΔRHI и полоса; вывод — одна строка в worklog.
5. **Пломба** (SEALS) — событие замера становится фактом дома.

## 6. Антигейминг (наследие MODULE B · CANCER_FILTER)

1. **Каждый прокси обязан иметь цену подмены** — колонка в §2. Прокси без цены подмены
   не входит в композит (пока-ёке источников C: ошибку сделать трудно, а не запрещать
   её ловить).
2. **Ротация**: раз в квартал 1/3 прокси пересматривается; прокси, который можно
   улучшить накруткой дешевле, чем работой, выводится.
3. **Exit-cost аудит**: незаменимость = рак. Если прокси растёт вместе с exit-cost
   клетки (P-κ2), метрика раковая — отключается независимо от красивых значений.
4. **Hold-out**: человеческие метки §4 п.3 — единственный судья джаджа; «самоверификация
   без внешнего критерия» — запрещённый паттерн (грабля Д-класса доктрины).
5. **Знак важнее величины**: контур реагирует на ρ̇<0, а не на абсолютные значения —
   абсолютами проще всего хвастаться.
