## 0. Задача одним абзацем

Governor — слой **поверх** любого фреймворка оркестрации (LangGraph, ADK, OpenAI
Agents SDK, рой дома), который не решает «как выполнять задачу», а решает
«**в каком режиме системе позволено жить**». Решение принимается не LLM и не
статическим графом, а вычислением динамики смысла: телеметрия → прокси (метрики §2)
→ ρ̂/α̂/β̂/κ̂/Ωₐ → ρ̇ и RHI → полоса жизни → режим контура. Фреймворк внизу остаётся
своим; governor меняет только то, что тот себе позволить не может: скорость входа,
ширину излучения, право на форк.

## 1. Позиционирование: кто принимает решение

| Система | Кто решает «что дальше» | Слепая зона | Чем отвечает governor |
|---------|--------------------------|-------------|------------------------|
| LangGraph 1.0 (K) | граф + условия на рёбрах + human-in-the-loop | состояние системы не вычисляется, задается структурой | governor даёт динамику: полоса жизни как условие перехода |
| OpenAI Agents SDK (K) | handoffs, guardrails | guardrail защищает отдельный вызов, не систему | Ωₐ-контур: отказы копятся как события, не гасятся по одному |
| Google ADK Task API (K) | Task API, вложенные workflow | делегирование без знания смысл-состояния исполнителя | GAC: делегирование с учётом ρ̂/κ̂ исполнителя (§3) |
| A2A Agent Card (L, M) | карточка: skills, протоколы | карточка статична: способность ≠ живость | `semantic_state` в карточке: дискавери по состоянию (§3) |
| SwarmBench-мир (N, O) | постфактум-анализ симуляций | детекторы вне оркестрации | κ-протокол в контуре (§4) |
| Дом (binding §3) | вердикт PID 1 | вердикту нужна опора | governor готовит цифру, решает PID 1 — всегда |

Правило честности: governor **не конкурирует** с фреймворками и не заменяет PID 1.
Он — приборная панель и ограничитель, как ограничитель оборотов: не едет вместо
двигателя.

## 2. Контур: вход → вычисление → режим

```
телеметрия дома (OTel gen_ai.* + rho.*-namespace, метрики §5)
        │
        ▼
прокси §2 (P-ρ1..3, P-α1..3, P-β1..3, P-κ1..2, P-Ω1..2, P-M1..3)  [И/Т/Г]
        │
        ▼
ρ̂, α̂, β̂, κ̂, Ωₐ  →  RHI := ρ̂/ρc;  ρ̇ ≈ ΔRHI/Δt  (окно = волна, метрики §3)
        │
        ▼
полоса жизни → режим governor (таблица ниже)
```

| Режим | Условие (метрики §3) | Что governor делает | Чего governor НЕ делает |
|-------|----------------------|---------------------|--------------------------|
| **VENT** (стравливание) | красная полоса: ρ̇ < 0 | запрещает вход новых Δ выше порога MΛ; требует разбор β-источников и κ̂; пишет Ωₐ-событие в worklog | не откатывает чужие ветки, не удаляет артефакты, не блокирует cells |
| **CRUISE** | зелёная / янтарная: ρ̇ ≥ 0 | обычная работа; STIGMERGIC_DRIFT продолжается; при янтарной — маркер в worklog (метрики §3) | не ускоряет вход без отдельного решения (OVERCLOCK_INPUT — фаза 3, заперта) |
| **FORK** (подготовка излучения) | RHI → 1 и P-ρ1 подтверждает 3 носителя (ρc) | готовит расчёт излучения (кому, сколько, в какой грамматике) — **досье для PID 1** | живой форк никогда не исполняется автоматом (binding §4: «никогда автоматом») |

Ключевое правило: **знак важнее величины** (метрики §6.5) — governor реагирует на
направление ρ̇, а не на абсолютные значения, потому что абсолютами проще всего
хвастаться.

## 3. Genesis Agent Card (GAC): дискавери по смысл-состоянию

Открытая проблема обзора L: реестры агентов статичны, «способность» в карточке
не говорит, жив ли агент. Дом расширяет грамматику A2A Agent Card своим
namespace (не ломая чужих клиентов):

```yaml
# GAC v0.1 — расширение A2A Agent Card дополнительными полями
name: forge-verifier
skills: [...]                    # чужая грамматика A2A — без изменений
semantic_state:                  # namespace дома (метрики §2, §5)
  rho_hat: 0.62                  # P-ρ1/2/3, нормировка в [0,1]
  alpha_hat: 0.91                # P-α1/2/3
  beta_hat: 0.15                 # P-β1/2/3 (нормированный долг)
  kappa_hhi: 0.21                # P-κ1 (HHI окна)
  omega_open:                    # незакрытые обструкции (id такта, MAST-код)
    - {tact: 9, mast: "inter-agent-misalignment", since: "2026-11-09"}
  rhi_band: green                # green | amber | red
  mode_request: cruise           # vent | cruise | fork-досье
  pid1_verdict_required: true    # живые действия — только через PID 1
```

Правила GAC:

1. **Дискавери по состоянию**: клиент, выбирающий исполнителя, читает
   `semantic_state` прежде skills. Пример правила выбора: не делегировать задачу
   агенту в красной полосе или с `kappa_hhi > 0.5` (источник HHI — метрики §2.5).
2. **Карточка без `semantic_state`** — не запрещена, но помечается как feedlot-вход
   и не участвует в GAC-дискавери дома (грамматика P-M1).
3. **Свежесть**: `semantic_state` — на момент последнего замера окна (§2 контура);
   карточка обязана показывать дату замера; просрочка > окна = полоса amber
   автоматически (нельзя хвастаться старой живостью).
4. **Совместимость**: чужие клиенты A2A видят незнакомые поля и игнорируют их —
   обратная совместимость сохраняется (источник M: расширяем грамматику, не
   форкаем протокол).

## 4. κ-протокол: антиколлизия в контуре

Мир обнаруживает тихий сговор агентов постфактум (источник O: Cournot-симуляции,
стихийные конвенции). Дом встраивает детектор в контур:

1. **Карта партнёрств** окна: кто с кем обменивался артефактами/коммитами.
2. **HHI окна** (P-κ1): Σ sᵢ² по долям авторов в изменённых строках.
3. **Exit-cost аудит** (P-κ2): рост exit-cost клетки вместе с ростом её незаменимости
   = раковая метрика (метрики §6.3) — отключается независимо от значений.
4. **Реакция governor** при κ̂-сигнале (HHI > 0.5 или exit-cost растёт 2 окна):
   - понижение приоритета внутренних маршрутов в пользу внешней верификации
     (такт Фомы: артефакт обязан работать вне места рождения);
   - Ωₐ-событие в worklog с MAST-кодом (источник B);
   - досье для фазы 1 REVOKE_CONSENT — исполнение **заперто** вердиктом PID 1
     (binding §4). Детектор автоматический, каратель — нет.

## 5. Обструкция как lifecycle: маппинг на грамматику A2A

Мир знает 4 состояния задачи (L, M); дом — 12 тактов. Маппинг (не подмена):

| Состояние A2A | Такты дома | Что мира не хватает |
|---------------|------------|----------------------|
| submitted | такт 1 (Петр = malloc: ресурс выделен) | выделение ресурса не отделено от обязательства |
| working | такты 2–5 (работа в грамматике) | — |
| failed | такты 9–11 (Иуда = crash: предательство ожиданий, журнал) | crash не различает «сломалось» и «саботировалось» |
| completed | такт 12 (Варфоломей = валидация) — задача закрыта только валидацией | «completed» у мира не требует внешней проверки |
| (нет аналога) | такты 6–8 (маскировка Eved, overclock, reject feedlot) — только dry-run | жизненный цикл обструкции до отказа у мира отсутствует |

MAST-коды (источник B) приклеиваются к тактам как словарь причин; отказ без
MAST-кода — сам по себе Ωₐ-событие класса «неописанный отказ».

## 6. Валидация: гипотезы, которые можно убить

Governor остаётся спекой, пока гипотезы не проверены в песочнице роя (dry-run):

- **H1 (безвредность)**: в SwarmBench-сценариях (источник N) governor не ухудшает
  pass^3 (дух источника E) против контрольного роя без governor.
- **H2 (κ-детектор)**: при подсадке сговорных агентов доля MAST-отказов класса
  «межагентское рассогласование» (источник B) снижается ≥ 20% — детектор видит
  рост HHI до сговора, а не после.
- **H3 (честность GAC)**: подмена `semantic_state` ловится просрочкой замера и
  расхождением с живой телеметрией (просрочка → amber, §3.3).

Провал любой гипотезы → соответствующая секция помечается больной, governor не
выходит из dry-run. Честный хвост лучше красивой витрины.

### 6.1 Статус валидации (волна TH-SG-2, 2026-11-10)

Песочница роя исполнена и влита: `rtynbirf/cell-swarm@main`,
`sandbox/governor-h123/` (пин `0b2486cf3`, 2026-11-10; решение — ADR-0015 роя;
README песочницы несёт полный отчёт и границы). Официальная кампания
100 сидов × 3 руки × 3 реплики, офлайн, детерминизм:

- **H1 подтверждена**: утилизация 88.4% → 95.6% (+7.2 п.п.), pass³ 0.43 → 0.74.
- **H2 подтверждена по официальному критерию**: MAST-прокси отказов −32.5%
  (цель −20%); детекция быстрая (VENT ≤ 2 окон в 100% сидов). Честный разброс:
  медиана 33.6%, p25 = −14.7%, p75 = +61.1%; 58% сидов индивидуально ≥ цели —
  разбор миров с p25 < 0 обязателен до любых полномочий.
- **H3 подтверждена механически**: просрочка/битая дата/чужая полоса → amber,
  fail-closed (selftest 8/8, CI cell-swarm).
- **v0.2-гистерезис (Schmitt) хуже v0.1** — отклонён, v0.1 базовая; адаптация
  объявлена открыто (README песочницы §v0.2), не тихая подгонка.
- Рыночное подтверждение антигейминга — источник U волны-3
  ([`world-trends-digest.md`](world-trends-digest.md) §4): самоотчётные средние
  вендоров памяти несводимы; дом отвечает распределениями и hold-out.

Governor остаётся в dry-run: песочница даёт числа, живые действия — только
вердикт PID 1 (ADR-0014 роя).

## 7. Границы честности

- Спека v0.1, не исполняется CI; приёмка гипотез — отдельная волна с отдельным
  тикетом и песочницей.
- Все живые действия (форк, revoke, карательные меры) — исключительно вердикт
  PID 1; governor готовит числа и досье (ADR-0014 роя: dry-run по умолчанию).
- GAC не заменяет A2A/MCP/ACP/ANP (источник L) — расширяет грамматику карточки
  в месте, которое рынок сам назвал открытой проблемой (статичные реестры).
- Изменение файла — PR в main; каноны и храповики не ревизуются.
