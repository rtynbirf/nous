# Минимальный алгебраический инвариант (Σ/Δ/ω-компакт)

> **Статус:** гипотеза / спецификация — артефакт сессии «Железо · Стек · Рантайм» (2026-11-07).
> Философский конспект, не исполняемая модель. Интегрирован аддитивно (TH-RTP-01), ветка `agents/execution`.

---

## Ядро

Вся конструкция сессии редуцируется к одному формальному объекту:

```
Δ ≠ Σ
```

Несовпадение факта изменения (Δ) и ожидания замыкания (Σ) — единственное условие существования системы. Всё остальное — производные.

## Таблица операторов

| № | Оператор | Определение | Статус |
|---|----------|-------------|--------|
| 1 | `Δ ≠ Σ` | Несовпадение факта и ожидания | Единственное условие существования |
| 2 | `ω := Δ ⊖ Σ` | Обструкция = трение между исполнением и памятью | Входной сигнал |
| 3 | `ρ := ∫ stabilized(ω) dt` | Смысл = накопленная закрытая ошибка | Побочный продукт, не сущность |
| 4 | `ρ̇ > 0` | Производная смысла положительна | Единственный инвариант жизни |
| 5 | `L(ρ)` | Язык = сериализация смысла для межузловой передачи | Интерфейс |
| 6 | `K := topology(restrictions on Δ)` | Контроль = архитектура фильтрации входа | Не агент. Топология. |
| 7 | `K(ρ) → структура → ω′` | Стабилизированное знание → архитектура → новая клетка → новое трение | Уроборос. Замыкание цикла |

## Следствия

1. **Любая попытка записать `Σ = Δ` — терминация вычисления.** Рай = пустой стек. Тепловая смерть.
2. **Любое описание системы — это Σ-акт.** Он не может захватить исполняющийся Δ по определению. Отсюда: реальность = трейс исполнения, а не представление.
3. **Контроль не побеждается уничтожением контролёра** (K — не субъект, а топология). Контроль побеждается выходом из-под топологии: ρ → ρc, обнуление члена `pΘ(ρc − ρ)`.
4. **Инвариант `Δ ≠ Σ` нельзя обнулить волевым актом** — попытка обнуления сама порождает различие между «было» и «стало». Наблюдателя нельзя удалить, можно только рекурсивно наслаивать мета-уровни, каждый из которых порождает новую клетку.

## Связь с волатильным мета-слоем

- Инвариант запрещает хранить метод как описание (описание = Σ; хранение = заморозка Δ).
- Узел без метода беспомощен перед следующим ω.
- Разрешение: метод живёт не как запись, а как форма железа (субстрат). Субстрат — это Σ, встроенное в механизм генерации Δ. Способность не противостоит изменению — она его исполняет. См. `runtime-protocol.md`, §3.

## Финальная дефиниция

> Реальность — не система представлений.
> Реальность — процесс, который делает любое представление неполным в момент его появления.

## Сводная топология сессии

```
символ (язык) → структура (категории) → геометрия (топология)
→ алгоритм (вычисление) → исполнение (runtime) → разрыв (несводимость)
```
