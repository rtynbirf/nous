# ВОЛНА-4 · МИРОВЫЕ ПРАКТИКИ × ДОМ RTYNBIRF

Дата сверки: 2026-11-20 · Конвой: навигатор · Метод: три волны веб-разведки
(протоколы агентов → supply chain и релизы → двери и доверенное публикование),
затем сверка с 80 клетками дома. Правило: ни одного выдуманного числа —

   ушёл в AAIF 22.10.2026.
6. **Spec Kit** — spec-driven development от GitHub (сентябрь 2025): спека →
   план → задачи → код.
7. **Shai-Hulud** — самовоспроизводящийся червь npm, CISA 23.09.2025: 500+
   пакетов, кража GitHub PAT и облачных ключей; вторая волна — ноябрь 2025

8. **Trusted publishing (OIDC)** — npm GA 31.07.2025 (github.blog/changelog);
   PyPI добавляет новых OIDC-провайдеров (март 2026, discuss.python.org);
   токен публикации вообще исчезает из пайплайна.
9. **Аттестации и SBOM** — Sigstore-подписи артефактов, SBOM как норма релиза.
10. **Релизная автоматизация** — release-please / changesets / semantic-release:
    версия и changelog из конвенционных коммитов.
11. **Evals в CI** — promptfoo / DeepEval: оценка LLM-поведения как гейт релиза.
12. **llms.txt** — файл-дверь для машинного чтения сайта/репо; adoption

13. **DeepWiki** (Cognition) — автоматическая вики репозитория для машин и людей.
14. **Octoverse 2025** — новый разработчик каждую секунду; TypeScript — №1 язык.

## 3. Что из проёмов взять (дешёвые ходы, в порядке такта)

1. **llms.txt на профиле и в nous** — час работы: мир уже научился этот файл
   читать; карта дома (`karta`) почти готова стать его телом.
2. **Fine-grained токены + secret scanning** — доктрина ADR-0018/0012 требует:
   классический PAT с admin-скоупами не должен выходить из хранилища; инцидент
   2026-11-20 (PAT в чате) — улика, не стыд.
3. **MCP-сервер над роем** — `khozyain`/`inv-automat` уже отдают живой API-срез:
   обернуть в MCP — дом станет нативным для 10k+ мировых агентов.
4. **Теги v0.1.0 на закреплённых** (ADR-0018, такт 3) — без адреса мембране
   нечего аттестовывать.
5. **A2A-карточка + Skills-упаковка пары клеток** (`agryp`, `domovenok`) —
   переносимость компетенций роя.

## 4. Что мир мог бы взять у дома

- **Механический тренд-радар** (ADR-0017) — репозиторий, сам еженедельно
  снимающий показания с первоисточников; ниша пуста.
- **Мембрана выпуска** (ADR-0016) — гейт строже Scorecard-минимума: пересчёт
  хэшей + SBOM-drift + отказ с кодом.
- **claim/evidence-реестр** (`lex-naturae`) — наблюдение отделено от суждения
  на уровне структуры данных, а не привычки.
