# Аксиомы SINGULARIS v2.0

Эволюция аксиом НОУС 0.4.0.
Каждая аксиома теперь имеет **операциональное следствие**.

Статус: A1–A6 — действующие аксиомы НОУС (`docs/concepts/axioms.md`), здесь переформулированы
операционально. A7–A8 — **кандидаты** до закрытия тикета 0010 (Фаза 1 runtime):
принятие через ADR + Human approval (уровень L3, `safety-governance.md`).

## A1. РЕПО = ОРГАНИЗМ
Файлы — геном. Поведение возникает только из работающего контура.
**Следствие:** без runtime субъекты — мёртвые декларации.

## A2. КАРТА = ТЕРРИТОРИЯ
CI + verifier принуждают совпадение утверждений с реальностью.
**Следствие:** любой claim в evidence должен быть воспроизводим.

## A3. САМОДОСТАТОЧНОСТЬ
`git clone` + одна команда → среда + зелёные тесты + работающий контур.
**Следствие:** bootstrap.sh поднимает и runtime.

## A4. N = СУБЪЕКТ ≠ ИНДИВИД
Права, scope, budget, tools и протокол отчёта живут в машиночитаемом контракте.
**Следствие:** runtime отказывает субъекту, нарушившему контракт.

## A5. СИНГУЛЯРНОСТЬ ИСТОЧНИКА
Один источник истины. У каждого артефакта — генеалогия (provenance).
**Следствие:** evidence-before-effect. Нет durable evidence — нет эффекта.

## A6. ЭМЕРДЖЕНТНОСТЬ
Поведение организма больше суммы файлов (слой state + evidence + live runtime).
**Следствие:** status-команда должна показывать живое состояние, а не только файлы.

## A7. ЭВОЛЮЦИЯ ПОД КОНТРОЛЕМ (кандидат)
Scaffold (контракты, промпты, verifier-правила, budgets) может улучшаться,
но только через ADR + evidence + oversight.
**Следствие:** нет «тихого» самоулучшения. Каждое изменение scaffold — тикет.

## A8. BUDGET — ЗАКОН (кандидат)
Каждый субъект и каждый run имеют hard ceiling.
**Следствие:** превышение budget = немедленный kill + evidence о причине.
