# МАНИФЕСТ ЭМЕРДЖЕНТНОСТИ SINGULARIS

**Дата:** 2026-10-29
**Статус:** онтологическая декларация (влита в НОУС 0.5.0 — ADR-0013)

## 1. Исходный хаос

Мир 2026 года переполнен агентами.
LangGraph, CrewAI, AutoGen, Hermes, code-evolve, self-evolving repos, RSI-исследования, provenance-системы, AGENTS.md-стандарты.

Все они решают куски проблемы.
Никто не решает проблему **репозитория как организма**, который:
- имеет конституцию,
- порождает субъектов с жёсткими границами,
- исполняет только под доказательствами,
- помнит свою генеалогию,
- эволюционирует scaffold, а не только код,
- остаётся самодостаточным после `git clone`.

## 2. Эмерджентный синтез

SINGULARIS возникает на пересечении:

- **Иерархическая оркестрация** + explicit contracts (best practices 2026)
- **Evidence-before-effect** + signed provenance graphs (Janus, execution provenance surveys)
- **Scaffold self-improvement** вместо слепого RSI модели
- **Repo-as-knowledge-factory** + living codebase
- **Аксиоматический организм** НОУС
- **State hashing + budget kill-switches** против loops
- **Verification subagent** как независимый иммунитет

Из этого пересечения рождается не «ещё один фреймворк», а **универсальный прототип контура**.

## 3. Сингулярность

Сингулярность здесь — не взрыв интеллекта.
Это **точка, после которой репозиторий перестаёт быть пассивным**.

Он начинает:
1. Сам чувствовать drift между картой и территорией.
2. Сам порождать тикеты.
3. Сам назначать субъектов.
4. Сам требовать доказательств перед эффектом.
5. Сам обновлять свой scaffold (промпты, контракты, verifier-правила) под контролем oversight.

## 4. Универсальность

Прототип применим к:
- любому git-репозиторию,
- любому набору LLM (локальные / API),
- любому уровню автономии (от HITL до почти-RSI),
- любому домену (код, документация, инфраструктура, исследования).

## 5. Уникальность

Отличие от всех существующих:

- Конституция первична (не код).
- Субъект = контракт + runtime + verifier, а не «агент с ролью».
- Эффект невозможен без durable evidence.
- Эволюция идёт через ADR + evidence, а не через «просто улучшилось».
- Организм остаётся читаемым человеком и исполняемым машиной одновременно.

## 6. Обещание

SINGULARIS не обещает суперинтеллект.
Он обещает **порядок, вносимый в хаос агентов**,
и **истину, которая имеет генеалогию**.
