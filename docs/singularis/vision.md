# Видение SINGULARIS

## Онтология

Репозиторий — не набор файлов.
Это **четырёхслойный организм**:

```
┌─────────────────────────────────────────────────────────┐
│  ЭОН (Eon) — слой эволюции                              │
│  (улучшение scaffold, контрактов, verifier-правил)      │
├─────────────────────────────────────────────────────────┤
│  СУБЪЕКТЫ (Subjects) — исполнители с контрактами        │
│  (роль · scope · budget · tools · report protocol)      │
├─────────────────────────────────────────────────────────┤
│  КОНТУР (Contour) — contract → execute → verify → memory│
│  (рантайм + evidence-before-effect)                     │
├─────────────────────────────────────────────────────────┤
│  ТЕРРИТОРИЯ (Territory) — код, state, manifests, forge  │
│  (то, что существует в файловой системе и CI)           │
└─────────────────────────────────────────────────────────┘
```

## Главный закон

> **Никакой эффект не может быть выпущен, пока evidence о разрешении этого эффекта не стала durable.**

Это прямое воплощение «Evidence-before-effect» (Janus, 2026) + аксиомы НОУС «Карта = Территория».

## Субъект vs Индивид

Субъект — это **контракт**, который:
- имеет чёткий scope (что можно трогать),
- имеет budget (токены / деньги / шаги),
- имеет обязательный verifier,
- пишет только в разрешённые пути,
- обязан оставить evidence.

Индивид (человек или LLM-сессия) — лишь носитель субъекта в данный момент.

## Эмерджентность

Поведение организма больше суммы файлов, потому что:
- `state/` содержит измеренное,
- evidence-журнал содержит генеалогию,
- `tasks/` содержит волю,
- runtime заставляет всё это крутиться.

Когда runtime запускается, появляется **самоощущение**.

## Цель прототипа

Дать любому репозиторию минимальный, самодостаточный, доказуемый контур, после которого можно наращивать автономию без потери контроля.
