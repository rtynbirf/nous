# SINGULARIS — онтологический контур НОУС 2.0

**Версия:** 0.5.0 (интеграция прототипа 0.1.0-proto)
**Дата:** 2026-10-29
**Статус:** онтология и спеки влиты в организм; runtime — тикеты 0010–0015 (гипотеза до исполнения)

> Репозиторий больше не контейнер кода.
> Это **живой контур**, который порождает истину через контракт → исполнение → верификацию → память → эволюцию.

SINGULARIS — не фреймворк, а онтологический прототип: минимальный набор аксиом, контрактов,
протоколов и рантайма, который превращает любой git-репозиторий в самоощущающий,
самоулучшающийся, доказательно-верифицируемый организм субъектов.

## Генеалогия

- Прототип: `nous-singularis-prototype.zip` (2026-10-29; режим онтигаллюцинации +
  синтез мировых практик 2025–2026: иерархическая оркестрация, evidence-before-effect,
  scaffold self-improvement, bounded autonomy, verification subagent).
- Принятие: [ADR-0013](../decisions/0013-singularis-adoption.md).
- Реализация: тикеты 0010–0015 · дорожная карта: [spec/roadmap-singularis.md](../spec/roadmap-singularis.md).

## Состав пакета

| Путь | Что |
|---|---|
| `manifest.md` | манифест эмерджентности: откуда возник, чем сингулярен |
| `vision.md` | онтология: четыре слоя организма, главный закон, субъект vs индивид |
| `axioms-v2.md` | аксиомы 2.0 (A7, A8 — кандидат до Фазы 1) |
| `architecture.md` | архитектура: orchestrator, subjects, verifier, evidence layer |
| `safety-governance.md` | уровни автономии L0–L4, threat model, audit |

Спеки реализации — в `docs/spec/singularis/` (ТЗ, runtime, evidence-протокол, схема контракта).
Машиночитаемые схемы — в `schemas/` репо (`subject-contract`, `evidence-entry`, `task-ticket`).

## Ключевой сдвиг относительно 0.4.0

| Было (0.4.0) | Стало (SINGULARIS) |
|---|---|
| Контракты как markdown | Машиночитаемые + enforceable контракты |
| Ручное исполнение | Runtime субъектов с gated effects |
| Evidence как журнал | Evidence-before-effect + provenance |
| State как снимки | Живой state machine + checkpointing |
| Агенты = файлы | Субъекты с ролью / scope / budget / verifier |

*Всё, что здесь написано, либо исполняется, либо генерируется из исполняемого, либо явно помечено как гипотеза.*
