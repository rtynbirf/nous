# TOFU-пломба первого огня форжа

Волна ×3 · W3-B · issue 14. Существующие `forge.yml` и `ci.yml` не тронуты —
это дополнение: формат пломбы, процедура и независимый сверяющий гейт.

## Идея (TOFU — trust on first use)

Доверие фиксируется в момент первого реального события, а не придумывается
заранее. Для форжа это значит: SHA256 берётся из артефакта, реально скачанного
при первом огне, и запечатывается в `manifests/pins.yaml`. Каждый следующий
сбор сверяется с пломбой; расхождение = красный до ADR.

## Формат блока (вставляется в manifests/pins.yaml после первого огня)

```yaml
first_burn:
  sealed_at: null      # UTC-метка первого огня (заполняется при пломбе)
  run_id: null         # run-id реального прогона forge
  artifacts: []
  #  - name: короткое имя артефакта
  #    path: путь, по которому артефакт скачивается/собирается
  #    sha256: SHA256 реально скачанного файла первого прогона
```

(заполняется при первом реальном прогоне; до пломбы гейт молчит и не красит)

## Процедура пломбы

1. Dispatch `forge` → дождаться success.
2. Скачать артефакт первого огня; локально: `sha256sum <файл>`.
3. Вписать `sealed_at`, `run_id` и строку артефакта с `sha256` в `first_burn`.
4. Коммит-пломба — одноразовый; перезакладка — только через ADR.
5. Далее каждый прогон: `python3 scripts/tofu_check.py --check <имя>=<путь>`.

## Гейт scripts/tofu_check.py

- `--list` — показать, что запечатано;
- `--check имя=путь` — сверить sha256 файла с пломбой (можно несколько раз);
- код 0 — зелёный; 1 — расхождение (красный до ADR);
  2 — артефакт не найден или имени нет в пломбе;
- `--selftest` — детерминированная самопроверка на временных файлах;
- пока `first_burn` пуст — гейт возвращает 0 с пометкой «ждёт первого огня».

## Связь с приёмкой issue 14

- «dispatch forge → success» и «first_burn с SHA256» — живой прогон и шаг
  пломбы выше;
- «тест-гейт CI↔пины зелёный» — selftest гейта зелёный уже в коммите; встройка
  вызова в джобу CI — одна строка владельца;
- «тикеты 0006/0003/0004 переведены» — шаг владельца по тикет-трекеру.

## Честный остаток

Пломбу нельзя выдумать заранее: значение появляется только из факта первого
огня. Формат и гейт готовы; вызов гейта из CI и перевод тикетов — за владельцем
(чужие файлы волной не правились).
