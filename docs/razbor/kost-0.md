## Почему это работает (коротко)

1. Признание сделано до первого содержательного хода — его нельзя
   использовать против содержания, оно стоит вне игры в опись.
2. Оно переводит «незаметную компакцию» (см. Чен, Governance Decay,
   dossier-research.md) в объявленную: среда больше не хранит разницу
   молча.
3. Оно структурно совпадает с требованием `src/runtime/harness/confession_test.py`:
   неисполненное обязано быть названо неисполненным, ядро не имеет права
   докладывать CONFIRMED без подтверждённого состояния.
