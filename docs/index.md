# НОУС — витрина знаний

НОУС — репозиторий, спроектированный как организм: файлы — геном, поведение возникает
из контура «контракт → исполнение → верификация → память». Человек и N агентов-субъектов
работают в одном теле по одним правилам. Эта документация собрана по Диатаксису:
учебники (Начало) учат, руководства (Практика) ведут за руку, понятия (Понятия)
объясняют «почему», референс (Референс) даёт точные факты.

## С чего начать

- Новичок: [bootstrap](getting-started/01-bootstrap.md) — от клона до зелёной верификации.
- Агент: [конституция](https://github.com/rtynbirf/nous/blob/main/AGENTS.md), затем
  [ветка исполнения](guides/execution-branch.md).
- Архитектор: [аксиомы](concepts/axioms.md), затем [ТЗ форжа](spec/tz-nous-forge.md).

## Карта знаний

| Квадрант Диатаксиса | Раздел | Вопрос |
|---|---|---|
| Учебник | getting-started | «Научи меня шагам» |
| Руководство | guides | «Как сделать X» |
| Понимание | concepts | «Почему так устроено» |
| Референс | reference | «Точные факты и команды» |

Спецификации (`spec/`) — мост между знанием и волей: ТЗ определяет цель, дорожная
карта — порядок, пакет реализации 01–07 — исполнимые модули. Решения фиксируются
ADR с обязательными разделами «ПОЧЕМУ ТОЛЬКО ТАК» и «ПО ДРУГОМУ НЕТ».

## Принцип чтения

Каждое утверждение здесь либо исполнимо (команда, тест), либо помечено как гипотеза.
Не нашёл доказательства — открой тикет `[bug]`: карта разошлась с территорией,
это дефект первого порядка.
