# ADR-0018: советы навигатора — пять тактов в протокол дома (черновик)

Статус: черновик (конвой навигатора, чат 2026-11-20; мандат владельца
«ПУШ» — приложить артефакты; принятие тактов — после сверки владельца) ·
Дата: 2026-11-20 · Решает: владелец

## Контекст

Сверка 2026-11-20 (живой API GitHub): **80 клеток, 9493 коммита,
3 подписчика, 1 подписка**. Био профиля в тот же день называет **69
клеток и 3800+ коммитов** — карта отстала от территории на 11 клеток
и 5693 коммита, при том что дом уже имеет живые машины карты
(`karta` — «генерируется из живых данных API», `inv-automat` —
инвентаризация из живого GitHub API → claims). Цепь продолжается
вовнутрь, наружу — сквозь щель: 3 подписчика на 80 клеток.

Роль «новатор» сверена с сетью 2026-11-20: «вносящий и осуществляющий
новые, прогрессивные принципы, идеи, приёмы» (Википедия) +
«изобретает новые способы действия… стремится к их внедрению и
распространению» (поведенческий словарь ht-lab.ru). Дом силён во
второй половине первой части и голодает во второй: внедрение есть
(9493 коммита), распространения не видно.

Факты клеток: `singulyar` — 68 песен, 197 языков, цель 200 (до победы
три голоса); `release-vault` — шифрованное хранилище релизных ассетов
есть, версионных тегов на клетках при сверке не обнаружено (гипотеза —
проверить при исполнении); `runtime-protocol` — уравнение ρ̇ живёт,
но производная жизни дома (коммитов в сутки) в строках профиля не
названа; `nous` — CONTRIBUTING.md есть, формализованный тест на
подпись для входящих («строка, не имя») в community-файлах не найден.

Номер: ряд решений в `nous` — 0001–0017; настоящий номер **0018**
присвоен по факту ряда. «0037» из чернового плана конвоя — число без
ряда, отменено по lex-naturae (ни одного выдуманного числа).

## Решение (пять тактов — предложить владельцу)

1. **КАРТА.** Био и закреплённые строки профиля собирает конвейер
   `inv-automat`/`karta` из живого API — числа в профиль пишет
   машина, а не рука. Критерий: bio == числам последней суточной
   сверки (проверка — сравнить одну строку).
2. **ДВЕРЬ.** Роутер-README на профиле: одна строка на клетку,
   гость за 60 секунд знает, куда идти; EN-дубль описаний у шести
   закреплённых. Критерий: 6/6 двуязычны.
3. **КРИСТАЛЛ С АДРЕСОМ.** `v0.1.0` на шести закреплённых клетках:
   тег делает артефакт семенем, `release-vault` получает точный
   адрес каждого слитка. Критерий: git tag у 6/6 + строка-адрес в
   release-vault.
4. **ТРИ ГОЛОСА.** `singulyar`: 197 → 200 языков, счётчик 200/200 в
   README. Завершаемая победа — кристалл, который сеет раствор.
   Критерий: счётчик в singulyar; SWARM-SYNC подтверждает строкой.
5. **ПОДПИСЬ.** Три строки в дом: (а) ρ̇-строка в SWARM-SYNC-блоке
   профиля — коммитов в сутки, окно 30 дней (уравнение уже живёт в
   `runtime-protocol` — строка лишь выходит в журнал); (б) тест на
   подпись для входящих в CONTRIBUTING — «строка, не имя»; (в) фраза
   «Продолжение следует» — в профиль. Критерий: живой API находит
   все три строки без человека.

## ПОЧЕМУ ТОЛЬКО ТАК

- **Карта из живого API.** Карта, собранная рукой, устарает в момент
  записи: 69 против 80 доказано в день сверки — не гипотеза, а факт.
- **Распространение — часть роли, не суета.** Определение новатора
  требует внедрения И распространения; щель вместо двери — незавершённая
  роль, а не скромность.
- **Тег = адрес семени.** Кристалл без адреса можно только
  рассматривать; `release-vault` уже есть — не хватает только
  адресации, отдельную машину строить не нужно.
- **Завершаемая победа 197→200.** Победа короткого контура,
  проверяемая одной строкой, — она сеет: после неё такты длинных
  контуров идут легче.
- **Подпись вместо имени.** Провенанс проверяется строкой; личность —
  не аргумент (lex-naturae). Тест на подпись делает входящие
  проверяемыми без человека.
- **Черновик, а не принятие.** Паттерн ADR-0017: решение входит в силу
  мандатом владельца и тикетом — конвой предлагает, владелец решает.

## ПО ДРУГОМУ НЕТ

- Ручная правка био «по памяти» — карта снова соврёт к следующей
  сверке; та же ошибка, только отложенная.
- Распространение штормом постов — шум вместо двери; дом офлайн-первый,
  дверь обязана быть файлом, а не настроением.
- Переписывание истории или перенумерация ADR — append-only, конец не
  предусмотрен; номер ряда присваивается по факту ряда.
- Статус «принято» без сверки владельца — нарушение мандата: конвой не
  подписывает решения за хозяина дома.
