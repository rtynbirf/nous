# ADR-0019: tombstone — смерть гипотезы в каноне обязана быть записана (черновик)

Статус: черновик (конвой навигатора, дубль два, чат 2026-11-20; мандат
владельца «ПУШ»; принятие — после сверки владельца) ·
Дата: 2026-11-20 · Решает: владелец

## Контекст

Дубль два — перепроверка волны-4 в режиме анти-галлюцинации: каждое
утверждение либо опирается на живой источник, открытый в заходе, либо
честно помечено «снимок». Проверке подвергнуты в первую очередь
собственные утверждения конвоя. Результат — две гипотезы канона умерли
за одну команду каждая.

**Гипотеза 1: «версионных тегов на клетках не обнаружено»** (ADR-0018,
такт 3, с пометкой «проверить при исполнении»). Проверка: `git ls-remote
--tags` — без лимитов API, одна команда. Итог: **7 из 7 витринных клеток
имеют теги** — `universal-agent` (v0.1.0, v2.2.0, v2.3.0), `singulyar`
(v0.5.3–v0.5.5, v1.7 + именные GOLOS-FOND-2026-11-15, MAIN-2026-11-11,
SINGULYAR-LINK-0.5.2, tombstone-refs-2026-11-09), `cell65-host`
(v1.0.0–v1.2.0 + mv3), `rtynbirf` (v0.1.0), `polymath-atlas-v107` (v0.1.0),
`lean-canon` (v0.1.0), `voice-atlas-llm` (8 датированных именных:
algoritm-deystviy-20261028, one-voice-20langs-20261028 и др.). Гипотеза
мертва; такт 3 «поставить v0.1.0 на закреплённых» теряет основание —
кристаллы уже адресованы.

**Гипотеза 2: «llms.txt в доме не найдено»** (волна-4, вердикт ПРОЁМ).
Проверка: raw-запрос по 11 клеткам. Итог: **6 из 11 живы** — `nous`,
`rtynbirf`, `voice-atlas-llm`, `universal-agent`, `polymath-atlas-v107`,
`cell65-host`; нет у `singulyar`, `lean-canon`, `karta`, `index`,
`door-zero`. Гипотеза умерла наполовину: дверь для машин частично
построена до конвоя.

**Уточнение без опровержения:** «301» в описании Lean-канона расшифрован
дословно по README: «канон: 301 Lean-модуль (Atlas · OSA/OSA4/OSA5 ·
Gestalt · Bridges · AtlasKO · UAM)» — модули, не теоремы.
**Расхождение, зафиксированное без угадывания:** живой HTML профиля даёт
7 витринных ссылок, ранняя сверка называла 6 закреплённых — открытый
вопрос для SWARM-SYNC.

Номер: ряд решений в `nous` — 0001–0018; настоящий номер **0019** присвоен
по факту ряда. «0030» из чернового плана конвоя — число без ряда,
отменено по lex-naturae; прецедент — ADR-0018 (там же отменён «0037»).

## Решение (tombstone-протокол — предложить владельцу)

1. **Два поля гипотезы.** Гипотеза, вписанная в канон (ADR, README,
   реестр), обязана нести: (а) способ проверки — одну конкретную команду
   (`git ls-remote`, raw-запрос, сравнение строк); (б) дату последней
   проверки. Гипотеза без обоих полей — не гипотеза, а ложь по
   расписанию: она стареет молча и становится ложью без события.
2. **Памятник вместо тихой правки.** Смерть гипотезы записывается
   tombstone-записью (настоящий ADR), а не затиранием строки: такт 3
   ADR-0018 пересобран из «поставить v0.1.0 на шести закреплённых» в
   «документ конвенции тегов» — semver v* для версий, датированные
   именные для событий (обе школы живы в доме: `universal-agent` и
   `voice-atlas-llm`), адресация слитков в `release-vault`.
3. **Питание канона.** Опровергнутая гипотеза — не позор, а еда:
   реестр дубль-два (`docs/genesis/dubl-dva-reestr-2026-11-20.md`) ведёт
   счёт УСТОЯЛО/ПОПРАВЛЕНО/СНИМОК и по миру (11/2/2), и по дому.

## ПОЧЕМУ ТОЛЬКО ТАК

- **Проверка — одна команда.** `git ls-remote --tags` стоит ноль лимитов
  и ноль минут; гипотеза, которая не проверяется одной командой, обязана
  прямо сказать, чего ей не хватает (токен, доступ, время).
- **Такт переходит, а не умирает.** Такт 3 не отменяется, а пересобирается:
  цель была «адресация кристаллов», и она достигнута жизнью раньше
  протокола; остаётся унификация конвенций — цель, проверяемая одной
  строкой реестра.
- **Tombstone, не стыд.** Паттерн дома: строка, не имя — улика сильнее
  репутации; ADR-0018 уже зафиксировал «гипотеза — проверить при
  исполнении», настоящий ADR исполняет проверку и хоронит остаток.
- **Черновик, а не принятие.** Паттерн ADR-0017/0018: конвой предлагает,
  владелец решает мандатом и тикетом.

## ПО ДРУГОМУ НЕТ

- Тихо поправить строку ADR-0018 без памятника — канон теряет историю:
  следующий конвой не узнает, что гипотеза уже умирала, и родит её заново.
- Оставить гипотезу без полей проверки — «ложь по расписанию» остаётся
  в силе: следующая сверка снова примет снимок за территорию.
- Копить расхождения молча (6 vs 7 витринных) — расхождение, не
  вынесенное на SWARM-SYNC, гниёт в снимке.

## Исполнение (при принятии)

Тикет в `tasks/open/`: (1) вписать два поля гипотезы в шаблон ADR и в
реестр дубль-два; (2) пересобрать такт 3 ADR-0018 строкой «конвенция
тегов»; (3) внести расхождение «6 vs 7» в повестку следующей SWARM-SYNC.
