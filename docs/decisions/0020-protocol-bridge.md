# ADR-0020: проект «Протокол-Мост» — перевод доказательств дома в протоколы мира (черновик)

Статус: черновик (конвой навигатора, дубль два, чат 2026-11-20; мандат
владельца «ПУШ»; принятие — после сверки владельца) ·
Дата: 2026-11-20 · Решает: владелец

## Контекст

Сверка дубль два (2026-11-20, живые источники) развела два крыла:

**Мир строит протоколы.** MCP передан в Linux Foundation 09.12.2025
(github.blog; тогда же основана Agentic AI Foundation); A2A — «surpasses
150 organizations … in first year» (пресс-релиз LF, 09.04.2026), v1 —
действующая спека; Agent Skills (SKILL.md) подарены Anthropic в AAIF
22.10.2026 (anthropic.com — дословно); llms.txt — формат с адоптерами
OpenAI, Anthropic, Gemini и аудитом Chrome Lighthouse (живая llmstxt.org);
npm trusted publishing (OIDC) — GA 31.07.2025. Червь Shai-Hulud (CISA
23.09.2025, «hundreds» пакетов по Unit42) показал цену классических PAT —
мир уходит на короткие машинные личности.

**Дом строит доказательства.** Мембрана выпуска (ADR-0016): пересчёт
хэшей, SBOM-drift, отказ с кодом — строже мирового Sigstore-минимума.
Тренд-радар (ADR-0017) — ниша, не занятая миром. Реестр улик
(`lex-naturae`, ADR-0011) — наблюдение отделено от суждения структурой.
Lean-канон — 301 Lean-модуль дословно (README) плюс 11 machine-verified
теорем (`polymath-stckg-core`).

**Щель.** Дом невидим для мировых агентов: MCP-сервера нет (корни 6 клеток
роя и полное дерево `nous` чисты — проверено дубль два), A2A-карточек нет,
llms.txt жив лишь в 6 клетках из 11 выборочных. Мир не имеет мембраны и
радара. Переводчика между крыльями нет.

Номер: ряд решений в `nous` — 0001–0019; настоящий номер **0020** присвоен
по факту ряда (прецедент перенумерации по lex-naturae — ADR-0018, ADR-0019).

## Решение (три пролёта — предложить владельцу)

1. **ДВЕРЬ (для машин-гостей).** llms.txt по формату llmstxt.org: H1 +
   блок-цитата + секции-ссылки. Довесить пяти клеткам выборки без него
   (`singulyar`, `lean-canon`, `karta`, `index`, `door-zero`); черновик
   домовой двери (58 строк, 6 секций, ~50 клеток) кузнечён конвоем и
   приложен к реестру. Критерий: raw-запрос `llms.txt` отвечает 200 на
   11/11 выборки; один гость-агент находит `karta` за одну сессию.
2. **РУКИ (MCP).** Минимальный MCP-сервер дома: JSON-RPC 2.0 поверх stdio,
   stdlib-only по духу дома; инструменты `list_cells` (живой срез, кеш
   10 минут), `cell_tags` (обёртка `git ls-remote` — без лимитов API),
   `house_pulse` (строка-снимок суточной сверки). Скелет кузнечён конвоем
   (~100 строк, помечен «черновик, не принят»). Перед принятием — сверка
   с живой спекой MCP (Linux Foundation) и тикет. Критерий: две команды
   извне (`tools/list`, `tools/call`) отвечают без человека.
3. **ЛИЦО (A2A-карточка).** Черновик карточки дома: имя, описание, 4
   навыка (`inventory-sweep` — inv-automat; `canon-audit` — lex-naturae;
   `media-forge` — singulyar; `release-membrane` — ADR-0016). Спека A2A v1
   конвоем дословно не открыта — поля сверить при принятии, числа не
   выдумывать. Критерий: карточка валидна валидатором живой спеки.

## ПОЧЕМУ ТОЛЬКО ТАК

- **Мост = перевод, не перестройка.** Все три артефакта уже кузнечены
  конвоем (llms.txt-черновик, mcp_skeleton.py, agent_card.json); дом
  копирует и сверяет, а не строит с нуля — цена принятия один тикет.
- **Мембрана остаётся ядром.** Протоколы мира дают доступ, мембрана дома
  даёт право; мост подключает `cell_tags`/`list_cells` к живым данным,
  но решение о выпуске по-прежнему за ADR-0016.
- **llms.txt — дёшево и проверяемо.** Файл — одна команда на клетку;
  дверь уже построена миром (OpenAI, Anthropic, Gemini публикуют) — дом
  лишь договаривает своё имя на уже существующем языке.
- **Доверие через улики.** Карточка и скелет несут пометки «черновик»,
  «сверить с живой спекой» — дом не подписывается под непроверенным
  (урок Shai-Hulud: ADR-0012, короткие машинные личности).

## ПО ДРУГОМУ НЕТ

- Ждать унификации протоколов мира — дом остаётся невидим для 10k+
  серверов MCP и 150+ организаций A2A; щель растёт сама.
- Строить свой четвёртый протокол — `runtime-protocol` уже жив и описывает
  динамику узла; мост лишь подключает его к чужим рукам и лицам.
- Публиковаться по классическим PAT — урок Shai-Hulud и ADR-0012 говорят
  против: OIDC/короткие личности, и только.

## Исполнение (при принятии)

Тикет в `tasks/open/`: (1) довесить llms.txt пяти клеткам и проверить
raw'ом 11/11; (2) перенести mcp_skeleton.py в клетку дома, сверить со
спекой, прогнать два вызова; (3) валидировать agent_card.json живым
валидатором A2A v1; (4) занести три критерия в реестр дубль-два и
проверить одной командой каждый.
