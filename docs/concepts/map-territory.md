# Карта = территория

Принцип: репо — карта мира; мир — территория. Польза карты прямо пропорциональна
совпадению с территорией, поэтому совпадение не предполагается, а принуждается
исполнимым контуром.

## Три класса утверждений

| Класс | Пример | Проверка |
|---|---|---|
| Исполнимое | «verify.sh проверяет пины workflows» | запусти тест |
| Сгенерированное | `state/снимок`, `SHA256SUMS`, `llms.txt` | перегенерируй, сравни |
| Гипотеза | «Fido v1.x жив и доступен» | помечена датой проверки в manifests |

Проза без класса в НОУС не существует: если утверждение нельзя ни исполнить,
ни перегенерировать, ни проверить по пину — оно помечается гипотезой с датой
или удаляется.

## Механизм принуждения

1. `tests/` — исполняемая карта: структура файлов, непрерывность ADR, пины по SHA
   в workflows, целостность ссылок документов. Сломал карту → красный CI.
2. `manifests/pins.yaml` — каждая внешняя зависимость с SHA/версией, источником
   и датой проверки. Сломался мир → видно, что именно и когда проверялось.
3. `state/` — периодическое самоизмерение: счётчики органов, свежесть пинов.
   Дрейф становится видимым до того, как станет аварией.
4. Отчёты субъектов — только сырые выводы команд. Пересказ не доказательство.

## Границы принципа (честно)

Карта не тождественна территории полностью: тесты проверяют согласованность
репо с собой, пины — состояние мира на дату проверки. Между проверками репо
живёт на допущениях — поэтому у каждого пина есть дата, а у гипотезы — метка.

**Почему только так.** Альтернативы: доверять памяти субъектов (не аудируется),
сверяться вручную (не масштабируется), не сверяться вовсе (xz-utils).
**По-другому нет.** Единственный дешёвый механизм совпадения — принудительный
исполнимый контур.
