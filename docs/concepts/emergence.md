# Эмерджентный контур

Эмерджентность — поведение системы, которого нет ни в одном её элементе. В НОУС
оно возникает из шестишагового контура, связывающего волю, исполнение, проверку
и память. Ни один файл не содержит «всего поведения» — оно воспроизводится циклом.

## Шесть шагов

1. **ТИКЕТ.** Воля оформляется как артефакт: `tasks/open/NNNN-*.md` с ролью, целью,
   границами и критериями приёмки. Настроение задачей не является.
2. **СУБЪЕКТ.** Агент берёт тикет только если тикет указывает его роль; действует
   строго в контракте `.claude/agents/<роль>.md`.
3. **ИСПОЛНЕНИЕ.** Ветка `agents/<роль>/<NNNN>-<slug>`, изолированные изменения,
   фиксация каждого нетривиального решения с альтернативами.
4. **ВЕРИФИКАЦИЯ.** `bash scripts/verify.sh` + CI: карта принудительно сверяется
   с территорией. Красный = задачи не существует.
5. **ПАМЯТЬ.** Исход шага фиксируется: ADR (почему так), CHANGELOG (что так),
   `state/` (каким организм был и стал), тикет → `tasks/done/` по вердикту
   верификатора.
6. **ЭВОЛЮЦИЯ.** Renovate/Dependabot дёргают зависимости, zizmor и gitleaks дёргают
   безопасность, `state/` дёргает свежесть пинов. Дрейф ловится до катастрофы.

## Откуда здесь эмерджентность

- Цепочка «тикет → субъект → верификация → память» никем не написана целиком:
  каждый файл описывает лишь свой шаг. Поведение возникает из их связности.
- Очередь `tasks/` превращает репо из хранилища в исполнителя: воля владельца
  распределена между N субъектами, репо «проглатывает» задачи и выдаёт доказательства.
- Слой `state/` даёт организму самоощущение: репо видит собственное состояние
  (счётчики, свежесть, дрейф) — и может инициировать собственное лечение тикетами.

## Инварианты контура (не нарушаются ни при каких задачах)

1. Красная верификация блокирует переход тикета в `done/`.
2. Деструктивные операции вне границ тикета — возврат и разбор.
3. Память дополняется, не переписывается: ADR не редактируются задним числом,
   исправления — новыми ADR со ссылкой.

**Почему только так.** Контур, заданный с первого коммита, прирастает правилами;
контур, добавленный поверх живого репо, конфликтует с уже накопленной историей.
**По-другому нет.** Эмержентность нельзя прикрутить — её можно только вырастить.
