# state/ — самоощущение организма (эмерджентный слой)

Сюда падают снимки измеренного состояния: `bash scripts/state.sh` создаёт
`snapshot-<дата>.md` (коммит, ветка, счётчики органов, тикеты open/done).

Правила:

1. Снимки создаются хронистом (`forge-librarian`) или владельцем — append-only:
   старый снимок не редактируется, новый — новый файл.
2. Снимок после значимой фазы обязателен (дорожная карта R5).
3. Дрейф видится разницей снимков: если счётчик ADR растёт без тикетов —
   появился «процесс без воли», тикет на разбор.

Ни один файл этого каталога не является источником истины о правилах —
только измерением. Истина — в конституции и manifests.
