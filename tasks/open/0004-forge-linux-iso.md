# Тикет 0004 — Linux-ветка форжа (равноправная)

Фаза: R4 (roadmap) · Создан: 2026-10-29 · Предусловия: 0001, 0002 (не зависит от 0003)

## Роль

forge-builder-linux (реализация), forge-architect (ADR при отклонениях от спеки).

## Цель

Модуль `src/forge/linux/`: netinst по пинам (Debian 12 firmware-вариант,
SHA256 сверен с официальным SHA256SUMS), рендер preseed с безопасными
дефолтами (confirm_nooverwrite=true, без автостирания), гибрид xorriso
(BIOS+UEFI: `-isohybrid-mbr` + `-eltorito-alt-boot`), SHA256SUMS, лог.
В CI — статические тесты на фикстурах.

## Границы

Разрешено: `src/forge/linux/**`, `tests/test_forge_linux*`. Запрещено: запись
на физические носители, непинованные зеркала, секреты в шаблонах (плейсхолдеры).

## Критерии приёмки

- [ ] Рендер preseed → инвариант «нет автоматического стирания» (тест-гейт)
- [ ] Аргументная строка xorriso сверяется с эталоном (тест)
- [ ] Фикстурный артефакт проходит SHA256-протокол (тест)
- [ ] Тикет не блокируется фазой R3 (проверка владельцем по истории веток)
- [ ] `verify.sh` зелёный; отчёт с сырыми выводами

## ПОЧЕМУ ТОЛЬКО ТАК

«+ЛИНУКС» — равноправная вторая ветка ТЗ, а не хвост Windows: независимость
фаз защищает поливариантность организма.
