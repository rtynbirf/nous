# Тикет 0006 — Первый реальный прогон форжа и TOFU-фиксация пинов

Фаза: R1+R4 приёмка (roadmap) · Создан: 2026-10-29 · Предусловия: 0002 (закрыт)

## Роль

forge-architect (запуск, калибровка пинов), forge-verifier (вердикт по артефакту);
исполняет человек-владелец или агент с правом workflow_dispatch.

## Цель

1. Запустить `.github/workflows/forge.yml` (debian12 и ubuntu-2404).
2. От артефактов прогона зафиксировать в `manifests/pins.yaml`:
   `iso_sha256` (TOFU), fingerprint подписи канала (TOFU), статус `calibrated`.
3. Прогнать `src/lib/verify-iso.sh` на артефактах; вердикт — в тикет.
4. Закрыть зависимые: тикет 0001 (калибровка) → done.

## Границы

Разрешено: `manifests/pins.yaml` (секция `forge:`), `state/`, этот тикет.
Запрещено: код, workflows, тесты.

## Критерии приёмки

- [ ] Обе Linux-цели собраны в CI; артефакты прогона получены
- [ ] `verify-iso.sh`: BIOS+UEFI El Torito, injected-файлы, размер — все гейты PASS
- [ ] pins.yaml: `iso_sha256` и fingerprint ≠ null, статусы `calibrated`, дата
- [ ] TOFU-фиксация отражена в `state/`

## ПОЧЕМУ ТОЛЬКО ТАК

Первый прогон — единственный честный источник значений пинов: выдуманный хеш —
фальшивая карта (аксиома 2), пустой пин — не принуждается. TOFU превращает
первый факт в постоянное принуждение.
