# Тикет 0007 — Закалка R6: QEMU-смоук, аудит-персона, релизный контур

Фаза: R6 (roadmap) · Создан: 2026-10-29 · Предусловия: 0006

## Роль

forge-architect + forge-verifier; хронист — state-снимки после приёмки.

## Цель

1. QEMU-смоук ISO в CI (серийная консоль, автоответ инсталлятора, таймаут) —
   загрузочная проверка артефакта, а не только структура.
2. zizmor `--persona=auditor` в CI; разобрать/зафиксировать advisory.
3. release-please (SemVer из Conventional Commits) вместо ручного CHANGELOG.
4. OpenSSF Scorecard workflow; copier-шаблон `templates/` (репо порождает репо).

## Границы

Разрешено: `.github/workflows/**`, `tests/**`, `scripts/**`, `templates/**`,
`docs/**`, CHANGELOG. Запрещено: manifests без ADR.

## Критерии приёмки

- [ ] QEMU-смоук зелёный в CI на фикстурной цели (или зафиксирован честный
      отказ с причиной и тикетом-преемником)
- [ ] zizmor auditor: 0 findings или ADR на каждый остаточный
- [ ] release-please ведёт CHANGELOG и теги
- [ ] Scorecard workflow жив; copier-шаблон инстанцируется

## ПОЧЕМУ ТОЛЬКО ТАК

Закалка после первой живой сборки (0006): ставить QEMU-гейт раньше факта сборки —
красная ложь на неродившемся артефакте. Порядок «факт → доказательство → закалка»
— это R5→R6 дорожной карты.
