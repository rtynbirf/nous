# Тикет 0013 — SINGULARIS: closed loop — скан порождает тикеты

Фаза: SINGULARIS-2/4 (roadmap-singularis) · Создан: 2026-10-29 · Предусловия: 0011

## Роль

forge-architect (контур сенсор → воля) + scan-субъект; verifier — forge-verifier.

## Цель

Фаза 4 дорожной карты: замкнуть контур «сенсор → воля → исполнение → evidence → state»:

1. `src/scan/scan.sh` при находках GAP/UNKNOWN пишет предложение тикета в
   `tasks/proposals/` (черновик в формате тикета, все 5 обязательных секций).
2. Человек (владелец) подтверждает: `tasks/proposals/NNNN-*.md` → `tasks/open/`
   (вручную или скриптом-помощником `scripts/promote_task.sh` с явным подтверждением).
3. Нумерация продолжается очередью (гейт непрерывности теста структуры не ломается).
4. Журнал скана фиксирует факт порождения предложения (evidence).

## Границы

Разрешено: `src/scan/**`, `tasks/proposals/**` (новый каталог), `scripts/promote_task.sh`,
`tests/**`, `docs/reference/structure.md`, CHANGELOG.
Запрещено: автоперемещение в `tasks/open/` без человека (L-гейт воли), правка чужих
тикетов, сеть вне allowlist скана.

## Критерии приёмки

- [ ] E2E: скан фикстуры с GAP → черновик тикета в proposals/ + evidence в журнале
- [ ] promote_task.sh без явного флага подтверждения отказывается работать
- [ ] Тест: непрерывность нумерации соблюдена при наличии proposals/
- [ ] verify.sh зелёный

## ПОЧЕМУ ТОЛЬКО ТАК

Скан уже видит территорию, но воля остаётся ручной — сенсор без мотора (фидбек N:
closed loop напрашивается). Автоперемещение в open/ запрещено сознательно: воля —
прерогатива владельца (Human accountability, L-гейты); организм предлагает, человек
распоряжается.
