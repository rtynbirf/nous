# Тикет 0012 — SINGULARIS: status — самоощущение организма

Фаза: SINGULARIS-1/4 (roadmap-singularis) · Создан: 2026-10-29 · Предусловия: 0010 (частично — независимо)

## Роль

forge-librarian (CLI) + chronist (state-интеграция); verifier — forge-verifier.

## Цель

FR-6 ТЗ: одна команда отвечает «что живёт и чем дышит»:

1. `scripts/status.sh` (+ make status): open/in-progress/done тикеты; последние runs и
   исходы (из журнала ledger); drift-индикаторы (карта vs территория: свежесть пинов,
   невалидированные claim'ы); budget spent за период (когда появится в 0010); health
   органов (форж: последний прогон CI; скан: последний журнал; тесты: локальный прогон).
2. Выход: человекочитаемый md-дамп в stdout + машиночитаемое дополнение в `state/`
   (без дублирования `state.sh` — статус читает, снимок пишет).
3. Никакой сети: всё из локальных файлов и журналов.

## Границы

Разрешено: `scripts/**`, `Makefile`, `tests/**`, `docs/reference/commands.md`, CHANGELOG.
Запрещено: запись в `state/` из status (разделение прав: state.sh пишет, status.sh читает),
сеть, `manifests/**`.

## Критерии приёмки

- [ ] `bash scripts/status.sh` за <2 сек показывает тикеты, health, drift — без сети
- [ ] Тест: статус на фикстурном репо соответствует содержимому каталогов
- [ ] `docs/reference/commands.md` дополнен; verify.sh зелёный

## ПОЧЕМУ ТОЛЬКО ТАК

Организм без самоощущения слеп (A6): гейты и журналы есть, но «одним взглядом» состояние
не видно — человек снова становится транслятором карты. Чтение без записи исключает
новый вектор порчи state/ — статус пассивен по построению.
