# templates/ — самокопирование (размножение организма)

Цель фазы R6: новый репо за одну команду с тем же геномом аксиом
(`clone → bootstrap → verify` зелёный на пустом месте).

## План внедрения (R6, тикет будет создан)

1. Инструмент — copier (обновляемые шаблоны, в отличие от cookiecutter):
   `copier.yml` + дерево-шаблон из текущего скелета.
2. Генерируемое: конституция, контракты, CI, manifests — копируется;
   ТЗ/спеки форжа — опционально (переменная шаблона `with_forge`).
3. Обновление порождённых репо: `copier update` поднимает изменения генома.

## Почему позже, а не сейчас

Шаблон снимается с живого организма, а не наоборот: пока не пройдены R1–R5,
скелет ещё не проверен боем; копировать непроверенный геном — размножать
дефекты. После R5 снимок снимается и замораживается пином версии шаблона.
