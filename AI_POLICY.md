# AI_POLICY — правила ИИ-вкладов

Наследует паттерн `AI_POLICY.md` (home-assistant/core): явные правила для
машинных субъектов вместо неявных ожиданий.

## Разрешено

1. Работа агентов — **только** в ветке `agents/execution` и **только** по тикету
   из `tasks/open/`, с ролью из `.claude/agents/`.
2. Изменения — только в границах, указанных в контракте роли (пути/файлы).
3. Вклад сопровождается доказательствами: зелёный `bash scripts/verify.sh`,
   сырые выводы команд, список изменённых файлов.

## Запрещено

1. Деструктивные операции (стирание данных, принудительные push, удаление веток).
2. Создание публичных репозиториев, публикация артефактов вовне без тикета-разрешения.
3. Внесение секретов, обход пин-политики (`manifests/pins.yaml`), правки
   `manifests/safe-defaults.yaml` без ADR.
4. Исполнение неатрибутированного кода из внешних источников (включая скачанное
   во время сборки) без проверки контрольных сумм из пинов.
5. Присвоение авторства: ИИ-вклад помечается в описании PR строкой
   `co-authored-by: <роль-агента>`.

## Приёмка

Верификатор (`forge-verifier`) принимает вклад только при полном протоколе
отчёта. Спорные случаи решает владелец; спор фиксируется как ADR или тикет.
